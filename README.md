# PDF → 엑셀 변환기

엑셀에서 'PDF로 저장'한 파일을 다시 편집할 수 있는 엑셀(.xlsx)로 되돌립니다.

> **파일은 서버로 전송되지도, 저장되지도 않습니다.**
> 지금 쓰고 있는 브라우저 안에서만 처리됩니다.

### [👉 바로 써 보기](https://seoinseok01.github.io/pdf-to-excel/)

---

## 왜 만들었나요

공공기관이나 회사에서는 엑셀 자료를 PDF로 바꿔 주고받는 일이 많습니다. 받은 사람이 그 숫자를 다시 쓰려면 표를 손으로 엑셀에 옮겨 적어야 하죠.

인터넷의 PDF 변환 사이트는 파일을 서버에 올려야 해서, 보안 규정이 엄격한 곳에서는 쓰기 어렵습니다. 이 변환기는 **변환 전체를 브라우저 안에서 처리**해서 파일이 컴퓨터 밖으로 나가지 않습니다.

## 할 수 있는 일

| | |
|---|---|
| **표 구조 복원** | 원래 시트의 열·행 격자, 병합된 셀, 여러 쪽에 걸친 표 이어 붙이기, 쪽마다 반복되는 머리글 제거 |
| **값 그대로** | `1,234` · `△1,234` · `(1,234)` · `15,000,000원` · `12.5%` · `2025. 3. 14.` 를 숫자·날짜로 바꾸면서 보이는 모양은 셀 서식으로 유지 |
| **서식** | 굵게, 글자색, 글꼴, 배경색, 테두리 두께와 색, 하이퍼링크 |
| **시트 정리** | 같은 시트였던 쪽은 자동으로 묶고, 화면에서 시트를 직접 합치기·나누기·되돌리기 |
| **옵션** | 칸 안의 여러 줄을 한 줄씩 다른 행으로 나누기 (한 줄에 한 행씩 쓴 양식용) |
| **결과 확인** | 미리보기, 예상 정확도와 글자 보존율 표시 |

## 정확도

원본을 알고 있는 시험 문서(가짜 데이터)를 실제 **Microsoft Excel**과 **LibreOffice**로 PDF 저장한 뒤, 변환 결과를 원본 엑셀과 칸 단위로 비교했습니다.

| 시험 문서 | 쪽 | 글자 | 숫자 | 굵게 | 테두리 | 병합 셀 |
|---|---:|---:|---:|---:|---:|---:|
| 예산표 (2단 머리글, △ 감소액, 비율, 반복 머리글) | 3 | 100% | 100% | 100% | 99.8% | 85.7% |
| 신청서 양식 (배경색, 굵은 테두리, 금액) | 1 | 100% | 100% | 100% | 94.7% | 26.7%¹ |
| 시트 3개짜리 문서 | 3 | 100% | 100% | 100% | 100% | – |
| 3,000행 대장 (가로 방향) | 112 | 100% | 100% | 100% | 100% | – |

<sub>Excel로 만든 PDF 기준이며, LibreOffice로 만든 PDF도 같은 결과입니다.
¹ PDF에는 선이 그려진 경계만 남기 때문에, 테두리 없이 합쳐진 칸이나 한 번도 선이 그어지지 않은 열 경계는 원래대로 되살릴 수 없습니다. 이 경우 보이는 모양은 같고 엑셀의 칸 나눔만 원본과 다릅니다.</sub>

112쪽짜리 PDF도 브라우저에서 **약 1.3초**에 변환되고, 그동안 화면이 멈추지 않습니다.

## 동작 원리

엑셀이 그린 PDF에는 원래 시트의 흔적이 남아 있습니다. 모든 테두리는 시트의 열 경계나 행 경계 위에 그려지기 때문입니다.

1. **읽기** — [pdf.js](https://mozilla.github.io/pdf.js/)로 글자와 위치, 선, 배경색, 클립 영역, 링크를 읽습니다.
2. **격자 복원** — 세로선의 x 위치를 열 경계로, 가로선의 y 위치를 행 경계로 삼아 원래 시트의 격자를 되살립니다.
3. **병합 판정** — 이웃한 칸 사이에 선이 없으면 합치되, 사방이 선으로 막힌 덩어리만 병합합니다. 그래서 표 밖의 제목이나 메모가 거대한 셀로 뭉치지 않습니다.
4. **쪽 잇기** — 열 경계가 같은 쪽은 한 표로 이어 붙이고, 반복 머리글은 지우고, 쪽 나눔에 갈린 병합 셀은 다시 잇습니다. 화면에 보이지 않게 잘린 글자(클립)는 버립니다.
5. **값과 서식** — 숫자·날짜를 인식하고, 글꼴 이름으로 굵기를, 그리기 색으로 글자색을, 선 두께로 테두리 굵기를 정합니다.
6. **엑셀 쓰기** — [ExcelJS](https://github.com/exceljs/exceljs)로 .xlsx를 만들어 바로 내려받습니다.

## 한계

- **스캔한 PDF**(사진처럼 된 PDF)는 글자 정보가 없어서 아직 변환할 수 없습니다.
- 셀 안에서 줄바꿈한 글자와 한 줄씩 다른 행에 쓴 글자는 PDF에서 똑같이 보여서, 화면의 옵션으로 고르게 했습니다.
- 체크박스의 체크 여부, 수식은 PDF에 남지 않아 되살릴 수 없습니다(수식은 계산된 값으로 들어갑니다).
- 엑셀과 LibreOffice로 만든 PDF로 시험했습니다. 다른 프로그램으로 만든 PDF는 결과가 다를 수 있습니다.

## 직접 실행하기

[Node.js](https://nodejs.org/) 20 이상이 필요합니다.

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 자동 검사
npm run build      # dist/ 에 배포용 파일 생성
```

명령줄에서 바로 변환할 수도 있습니다.

```bash
npm run convert -- 보고서.pdf 보고서.xlsx
npm run convert -- 신청서.pdf --split-lines   # 칸 안 여러 줄을 행으로 나누기
```

### 시험 문서 다시 만들기

```bash
node scripts/make-fixtures.mjs     # fixtures/xlsx/ 에 가짜 데이터 엑셀 생성
./scripts/print-fixtures.sh        # Excel(macOS)과 LibreOffice로 PDF 저장
node scripts/eval-fixtures.mjs     # 원본과 비교한 점수표 출력
```

## 폴더 구조

```
src/
  extract.mjs     PDF에서 글자·선·채우기·클립·링크 읽기
  table.mjs       격자 복원, 병합 판정, 글자 배치
  convert.mjs     쪽 잇기, 시트 묶기, 숫자·날짜·서식, 엑셀 쓰기, 예상 정확도
  preview.mjs     미리보기용 HTML 표
  node.mjs        Node에서 파일로 변환할 때 쓰는 입구
  ui/             웹 화면
tests/            자동 검사 (원본 엑셀과 비교, 규칙 검사)
fixtures/         가짜 데이터 시험 문서와 그 PDF
scripts/          변환·비교·시험 문서 생성 도구
```
